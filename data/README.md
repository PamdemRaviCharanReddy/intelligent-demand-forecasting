# Data Directory

This directory manages all raw, processed, and synthetic datasets. All data files are excluded from Git version control via `.gitignore` to avoid repository bloat and data leakage.

## Directory Structure
- `data/raw/`: Original CSV files (e.g. from Kaggle Favorita store sales).
- `data/processed/`: Cleaned, validated, and fused multi-source datasets ready for feature engineering.
- `data/synthetic/`: Benchmark synthetic dataset generated by `src/idfs/data/synthetic.py`.

---

## Instructions for Kaggle Favorita Real Data

To run the pipeline on the real Kaggle "Store Sales – Time Series Forecasting" dataset:

1. **Obtain API Key**:
   - Go to Kaggle -> Settings -> Account -> "Create New Token".
   - Save the downloaded `kaggle.json` into `~/.kaggle/kaggle.json` (on Windows: `C:\Users\<username>\.kaggle\kaggle.json`).

2. **Accept Competition Rules**:
   - Visit [Kaggle Store Sales Competition](https://www.kaggle.com/competitions/store-sales-time-series-forecasting) and accept the rules.

3. **Download Data**:
   ```bash
   kaggle competitions download -c store-sales-time-series-forecasting -p data/raw/
   # Or extract the files manually into data/raw/
   ```

4. **Required Raw Files**:
   Ensure `data/raw/` contains:
   - `train.csv` (sales, store_nbr, family, onpromotion)
   - `stores.csv` (store metadata: city, state, type, cluster)
   - `oil.csv` (daily oil prices)
   - `holidays_events.csv` (holiday and event schedule)
   - `transactions.csv` (daily store transactions)

If real data is not downloaded, the entire pipeline automatically runs using the realistic synthetic benchmark.
