Executive Summary

The Intelligent Demand Forecasting System (IDFS) is an end-to-end machine learning and operational research platform that bridges the gap between predictive modeling and inventory replenishment decisions. Built on a dataset of 219,000+ daily transactions across 15 retail stores and 20 seasonal products over 4 years, IDFS benchmarks 10 forecasting models, calibrates distribution-free uncertainty intervals, simulates inventory policies, explains predictions with Tree-SHAP, and monitors production data drift.

5 Core Research Novelties

  • N1: Cost-Optimized (R, S) Inventory Simulation — Discrete-event operational simulation evaluating carrying, stockout penalty, and replenishment costs under dynamic lead-time demand.
  • N2: Conformalized Quantile Regression (CQR) — Distribution-free prediction intervals calibrated on held-out data to guarantee finite-sample coverage without assuming Gaussian errors.
  • N3: Syntetos-Boylan Demand-Pattern Router — Automated time-series classification via Average Inter-demand Interval (ADI) and squared Coefficient of Variation (CV²) into Smooth, Intermittent, Erratic, and Lumpy demand quadrants.
  • N4: Automated Drift Monitoring & MLOps Guardrails — Continuous tracking of covariate and concept shifts via Population Stability Index (PSI) and Kolmogorov-Smirnov (KS) tests.
  • N5: Tree-SHAP Model Explainability — Game-theoretic feature attribution decomposing predictions into exact marginal contributions for complete transparency to store managers.

Installation & Quickstart

# 1. Environment Setup
uv venv --python 3.12 .venv
.venv\Scripts\Activate.ps1
uv pip install -e ".[dev]"

# 2. Launch FastAPI Backend Service (Port 8000)
uvicorn idfs.api.main:app --host 127.0.0.1 --port 8000 --reload
# Swagger docs: http://127.0.0.1:8000/docs

# 3. Launch Streamlit Frontend Dashboard (Port 8501)
streamlit run streamlit_app.py --server.port 8501
# Dashboard: http://localhost:8501
